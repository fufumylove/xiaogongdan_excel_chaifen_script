# 工价表转换工具（wage-converter）

从一份「产品制造工序工价表」总文件自动生成三份可导入的 xlsx：工序、工艺路线、绩效。

## 可行性分析

| 维度 | 结论 |
| --- | --- |
| 技术 | Python 3 + openpyxl + pytest，依赖少、安装简单；已在本机完整跑通 |
| 数据 | 总文件版式固定，五章节与工价列可稳定定位；示例 59 条工序全部正确解析 |
| 复用 | 产品号、产品名称、工序条数与内容均动态提取，不硬编码；同版式文件可直接复用 |
| 验证 | 11 项自动化测试（解析、生成、端到端、异常路径）全部通过，并与示例逐格回归 |
| 风险 | 仅支持版式一致的总文件；版式变化会明确报错，不会产出错误结果 |

## 环境准备

```bash
pip install -r requirements.txt
```

## 使用

```bash
python -m wage_converter.cli --input "9672848#冰包（双肩 条纹）.xlsx"
# 指定输出目录
python -m wage_converter.cli --input "总文件.xlsx" --output-dir ./output
```

不传 `--output-dir` 时输出到总文件所在目录。同名文件会被覆盖。

## 输出规则

1. `1.工序-{产品号}#{产品名称}.xlsx`：8 列；编号 `{产品号}-A01…E19`（1–9 补零）；名称 `工序内容-产品名称`；报工权限=`所有人`；报工数配比=`1`；不良品项列表=`其他`；加工类型、默认供应商、任务打卡留空。
2. `2.工艺路线-{产品号}#{产品名称}.xlsx`：3 列；编号 `{产品号}-01…05`，行序为车工→手工→备料→包装→裁剪；工序列表用中文逗号连接。
3. `3.绩效-{产品号}#{产品名称}.xlsx`：13 列；顺序与工序一致；计价方式=`计件`；工资单价取总文件工价（数值）；其余列留空。

与空间示例的差异均来自需求确认：工序由 6 列扩为 8 列；工艺路线行序由 04/03/02/05/01 改为 01→05。

## 测试

```bash
pytest -q
```

样本总文件与三份示例保存在 `samples/`，用于端到端回归；合成用例在临时目录生成，不入库二进制。
