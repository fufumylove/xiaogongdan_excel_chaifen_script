# PRD — 工价表转换工具

## 背景与目标
将「产品制造工序工价表」转换为可导入系统的三张表（工序、工艺路线、绩效），替代手工复制粘贴；工具需能处理同版式的其他产品总文件。

## 用户与角色
工艺/薪资维护人员，在命令行指定总文件路径即可获得三份 xlsx。

## 功能范围
- 输入：单个 xlsx 总文件。版式：A4 产品名称、D4 产品号；左侧 A/B/C 为车工工序（序号/内容/工价）；右侧 D/E/F 依次为手工、备料、包装、裁剪工序。
- 输出：`1.工序-…xlsx`、`2.工艺路线-…xlsx`、`3.绩效-…xlsx`；默认写在输入文件同目录，可指定输出目录。
- 解析：按章节标题定位区块；仅保留内容非空且工价可解析的条目；有效序号按章节内顺序重排，1–9 补零。
- 不修改输入文件；不处理版式不同的文件；不联网。

## 业务规则
| 对象 | 规则 |
| --- | --- |
| 工序编号 | `{产品号}-{字母}{序号:02d}`，A/B/C/D/E 对应车工/手工/备料/包装/裁剪 |
| 工序名称 | `{工序内容}-{产品名称}` |
| 工序列 | 8 列；报工权限=所有人；报工数配比=1；不良品项列表=其他；加工类型/默认供应商/任务打卡空 |
| 路线编号 | `{产品号}-01…05`；行序车工→手工→备料→包装→裁剪 |
| 路线名称 | `{章节名}-{产品名称}` |
| 工序列表 | 该章节全部工序名称，以中文逗号连接 |
| 绩效 | 13 列；产品编号/产品名称取解析值；计价方式=计件；工资单价=工价数值；其余列空 |

## 输入输出示例（9672848#冰包（双肩 条纹））
- 工序 59 行，示例关键值：`9672848-A01` / `双针拉拉尾×2-冰包（双肩 条纹）` / 报工权限 `所有人`。
- 路线 5 行：`9672848-01` / `车工-冰包（双肩 条纹）`。
- 绩效 59 行：工资单价 `0.04` 对应第一条车工工序。
- 有 3 处仅填序号、无内容与工价的行，示例未纳入，工具同样跳过。

## 验收标准
- 真实样本生成 59/59/5 行数据，表头与列序符合规则，关键单元格逐格一致。
- 与示例共有字段（编号、名称、工价、路线内容）回归比对一致。
- 更换同版式、不同产品信息的文件仍正确（合成用例覆盖）。
- 缺少产品信息/章节、文件损坏时明确报错，不产出半成品。

## 可行性与约束
- 依赖 openpyxl、pytest，均已验证可用；规则确定、无外部服务依赖。
- 约束：输入版式必须与样本一致；同名输出覆盖；工价文本型会转换并告警。

- 2026-11-26：工序由示例 6 列扩为 8 列；路线行序改为 01→05（均经用户确认）。
